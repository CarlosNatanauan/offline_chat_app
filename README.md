## ✨ What Is Caflow?

Caflow is a tiny, cozy, offline chat room that exists only **inside the café you're sitting in**.

It allows people in the same physical space to send messages to each other **without internet**,  
using a clever mix of:

- 🔍 Nearby Connections (Bluetooth + Wi-Fi scanning)  
- 📡 Wi-Fi Direct (actual chat link)  
- 🎭 Anonymous café-style nicknames  

No servers.  
No cloud.  
No login.  
Just *your phone talking directly to other phones*.

---

## 💡 Why?

Because sometimes you want to chat with someone nearby without:

- asking for their number  
- shouting across tables  
- using the café Wi-Fi that requires your mom’s maiden name  

Caflow gives you a **local-only, low-pressure, pocket-sized chat room**.

---

## 🚀 Features

### 🔌 100% Offline Messaging  
Messages travel directly via **Wi-Fi Direct**.  
Yes, **Wi-Fi must be ON**, but **internet is NOT required**.  
(Think of Wi-Fi Direct as walkie-talkies with better grammar.)

### 📡 Nearby Discovery  
Find other Caflow users in the café using **Nearby Connections**.

This uses:
- Bluetooth  
- Wi-Fi radio (not internet)  
- Location permission (Android requires it for scans)

### 💬 Modern Chat UI  
- Swipe-to-reply  
- Emoji reactions  
- Reply threads  
- Smooth message bubbles  
- Connection status banners  
- Auto-reconnect logic  

### 👻 Fun, Anonymous Display Names  
Pick from mysterious café-themed suggestions like:
- *Quiet Wi-Fi*  
- *Latte Mirage*  
- *Croissant Code*  
- *Espresso Shadow*  

Perfect for shy humans.

### 🔒 Privacy by Design  
- No messages leave the café  
- No accounts  
- No cloud storage  
- Nothing sent online  

---

## 🧠 How It Works (Short Version)

1. You open Caflow  
2. You pick a nickname that does NOT expose your tax returns  
3. The app scans for other phones using Bluetooth + Wi-Fi radio  
4. When you pick someone, a **Wi-Fi Direct** connection forms  
5. Messages flow **directly between the two phones**  

No router.  
No access point.  
No internet.  
Just phone → phone.

## 📡 Requirements (Android)

Android requires these to scan nearby devices:

| Feature | Why Android Requires It |
|--------|--------------------------|
| **Wi-Fi (ON)** | Needed for Wi-Fi Direct radio (NOT for internet) |
| **Bluetooth (ON)** | Required for Nearby scanning |
| **Location (ON)** | Mandatory for Bluetooth/Wi-Fi discovery |

Caflow **does NOT** use these to access the internet.
